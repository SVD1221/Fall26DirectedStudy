# Cellular Automata

| Directory | Description|
| --- | --- | 
| `1d` | Contains 1-dimensional cellular automata, e.g. elementary cellular automata (ECA).|
| `2d` | Contains a general 2-dimensional cellular automata model. Capable of running models such as Conway's Game of Life and a forest file model. |
| `output_files` | Contains the outputs generated by files in the directories `1d` and `2d`. |
