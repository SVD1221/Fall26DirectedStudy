# Cellular Automata

| Directory | Description|
| --- | --- | 
| `1d` | Contains 1-dimensional cellular automata, e.g. elementary cellular automata (ECA).|
| `2d` | Contains a general 2-dimensional cellular automata model. Capable of running models such as Conway's Game of Life. ALL 2D CA output is generated in `2d_ca.cpp`.|
| `Game_of_Life` | Contains the benchmarking of my Game of Life code compared to another C++ program. |
| `output_files` | Contains outputs and animations generated by files in the directories `1d` and `2d`. |
