# Output

| Directory | Description|
| --- | --- | 
| `1d` | Output of 1D CA, generated by `elementary_ca.cpp`. |
| `2d` | Output of 2D CA, generated by `2d_ca.cpp`. |
| `Game_of_Life` | Output of Conway's Game of Life simulations, generated by `2d_ca.cpp` and `GoL_BENCHMARK.cpp`. |
| `neumann` | Library of 2D CA animations that use the von Neumann neighborhood. |
